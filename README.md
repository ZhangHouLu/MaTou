# 张厚露 · 书条 —— 个人网站 v6「木质渔港」

纯静态，零依赖，零费用，无任何密钥。支持日间/夜间模式（右上角切换，自动记忆）。

## 本地打开

1. 双击 `index.html`（断网也能看）
2. 或本目录终端运行 `python -m http.server 8000`，访问 `http://localhost:8000`

## 设计语言（v7）

夜间改为**暖灯夜港**：深青蓝底 + 灯焰金强调 + 暖米白文字，面板层次拉开，
右上一团灯晕、左缘一抹月光、两层会呼吸的星星（白天自动收工）。
日间保持晒白的暖纸调。内容层新增：今日港况预报、码头常见问题（原生折叠）、
筐内统计、装筐三原则、答复速度、上船暗号、发货须知——全部可编辑，无编造事实。

## 像素海鸥独立存档 ⚓

- `pixel-gull/gull.svg` —— 独立的海鸥图（312×252 矢量，可直接当头像/素材用，浏览器打开即可另存为 PNG）
- `pixel-gull/gull-map.txt` —— 字符画源文件 + 图例
- `tools/export-gull.js` —— 导出脚本：从 `script.js` 读取像素图重新生成，
  改了海鸥后运行 `node tools/export-gull.js` 即可同步存档

## 文件结构

| 文件 | 作用 |
|---|---|
| `index.html` | 首页：大字宣言 + 运单介绍 + 码头舞台上的像素海鸥 |
| `about.html` | 关于：报关单 / 已登记爱好 / 航线日志（留白处未编造） |
| `works.html` | 作品：六个集装箱，虚位以待 |
| `contact.html` | 联系：两条"频道"（邮箱可复制 + Gitee）+ 投喂彩蛋 |
| `styles.css` | 全部样式，主题色在 `:root` |
| `script.js` | 像素图数据（`PIX`）、打字机、薯条雨、鼓捣签等 |
